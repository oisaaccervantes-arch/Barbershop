# Decisiones pendientes

## Disponibilidad de citas

Confirmar con el dueño cómo deben manejarse las citas simultáneas:

- Cada cita debe tener un barbero asignado.
- Varios barberos pueden atender citas a la misma hora.
- Falta definir si se debe bloquear automáticamente otra cita para el mismo
  barbero a la misma hora.
- Falta definir la duración de cada servicio y si deben bloquearse intervalos
  completos, no solamente la hora de inicio.
- Hasta confirmar estas reglas, el sistema exigirá seleccionar un barbero, pero
  no rechazará automáticamente horarios coincidentes.
